### Theme API to use in Task 5

`render_with_options(input, RenderOptions) -> anyhow::Result<String>`.

`RenderOptions { theme: Theme, layout: LayoutConfig }`. Presets: `Theme::mermaid_default()`, `Theme::neutral()`, `Theme::dark()`, `Theme::forest()`, `Theme::modern()`. `RenderOptions::default()` is `Theme::modern()`, not the classic theme.

Map `MermaidTheme`:

| Style | Theme constructor |
|---|---|
| `Default` | `Theme::mermaid_default()` |
| `Neutral` | `Theme::neutral()` |
| `Dark` | `Theme::dark()` |
| `Forest` | `Theme::forest()` |

Knobs (all `pub`, CSS colour strings unless noted):

- Background: `theme.background: String` (default `"#FFFFFF"`).
- Primary: `theme.primary_color: String` (default `"#ECECFF"`). Also `primary_text_color`, `primary_border_color`.
- Font: `theme.font_family: String`, `theme.font_size: f32`. The classic stack names Trebuchet / DejaVu Sans / Liberation Sans. Typst's embedded set is Libertinus Serif, New Computer Modern, New Computer Modern Math, and DejaVu Sans Mono. Set `font_family` to `"DejaVu Sans Mono"` when the World has only embedded fonts, or SVG text will not draw. The spike did this and the PNGs stayed readable.

`DiagramStyle.background`, when set, overwrites `theme.background` with `Color::to_typst`'s hex (or a `#rrggbb` form the renderer accepts).

Errors: `anyhow::Error` from `render` / `render_with_options`. `render_strict` returns `ParseError`.

## Typst 0.15.1 API (names that differ from the plan)

Pins: `typst`, `typst-pdf`, `typst-render`, `typst-kit`, `typst-ide`, `typst-layout` all `=0.15.1`. `PagedDocument` is **not** re-exported from `typst`; depend on `typst-layout` directly.

- `typst::compile::<PagedDocument>(world: &dyn World) -> Warned<SourceResult<PagedDocument>>`. `Warned { output, warnings }`. `output` is `SourceResult<T>`.
- `Library` comes from `LibraryExt`: `Library::builder().build()`. There is no `Library::build()` by itself.
- `World` (`#[comemo::track]`): `library`, `book`, `main`, `source`, `file`, `font`, `today(offset: Option<typst::foundations::Duration>) -> Option<Datetime>`. The spike and the engine return `None` from `today`.
- Fonts: `typst_kit::fonts::{FontStore, embedded}`. Features are `embedded-fonts` and `scan-fonts`. The plan's `fonts` and `embed-fonts` feature names do not exist. Tests use `default-features = false, features = ["embedded-fonts"]`. Do not enable package download features.
- `FileId`: `RootedPath::new(VirtualRoot::Project, VirtualPath::new("main.typ").unwrap()).intern()`. Paths: `id.vpath().get_without_slash()` (`as_rootless_path` is deprecated).
- One `Source` is kept. `Source::replace(&mut self, &str) -> Range` does the prefix/suffix diff.
- `typst_render::render(page, &RenderOptions) -> tiny_skia::Pixmap`. `RenderOptions { pixel_per_pt: Scalar, render_bleed: bool }`. Not `render(page, 2.0)`. `Scalar::new(f64)`. Pixmap pixels are premultiplied RGBA; unpremultiply before storing straight alpha.
- `typst::utils::hash128(&frame) -> u128`. `typst::comemo::evict(30)` after each compile.
- Introspector: `document.introspector()` is `&Arc<PagedIntrospector>`. `position(Location) -> Option<PagedPosition { page: NonZeroUsize, point: Point }>`. Page numbers from the introspector are 1-based.
- PDF: `typst_pdf::pdf(document, &PdfOptions) -> SourceResult<Vec<u8>>`. `PdfOptions` has no title/author fields. Set `DocumentInfo` on the document (`info_mut()`: `title`, `author: Vec<EcoString>`) before export.
- Missing files: `FileError::NotFound`. Package imports: `FileError::Other(Some(EcoString))`.
- A4 at 2 px/pt is 1191×1684.

## gpui-kit 0.8.0 notes (spike only)

- `gpui_kit::application().with_assets(gpui_kit::assets::Assets).run(...)`, then `gpui_kit::init` and `gpui_kit::open_window`.
- Editor is `gpui_kit::component::input::{Editor, EditorState, InputEvent}`. `value()` takes no context. `set_value` does not emit `InputEvent::Change`.
- `h_flex` / `v_flex` live in `gpui_kit::base`, not the prelude.
- Scroll: `div().id("page-preview").overflow_y_scroll()` (`overflow_scroll` is on stateful elements).
- Debounce with `cx.background_executor().timer` inside `cx.spawn`, then `background_spawn` for compile. Hold the world in `Arc<Mutex<_>>`. Dropping the `Task` cancels the previous debounce.
- Bitmaps: encode PNG with the `image` crate and `Image::from_bytes(ImageFormat::Png, bytes)`. The window was not opened, so image upload and the 120 ms debounce were not observed on screen.
